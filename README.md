## 🧾 Mini 抖音项目需求文档（PRD）

### 一、项目概述

**项目名称**：Mini 抖音（MiniTok）
**开发目标**：实现一个简化版的短视频分享平台，用户可以注册、登录、上传视频、浏览推荐视频流、点赞、收藏、评论。
**技术栈**：

* **前端**：Vue 3 + Vite + Pinia + Element Plus
* **后端**：Golang（Gin / go-zero / Fiber 三选一）
* **数据库**：MySQL + Redis
* **对象存储**：本地存储 / MinIO / 阿里云 OSS
* **鉴权机制**：JWT + Token 中间件
* **部署**：Docker Compose 一键部署

---

### 二、系统角色

| 角色   | 权限说明                   |
| ---- | ---------------------- |
| 普通用户 | 注册、登录、浏览、点赞、收藏、评论、上传视频 |
| 管理员  | 审核视频、删除违规内容、封禁用户       |

---

### 三、核心功能模块

#### 1. 用户系统

* **注册**：手机号/邮箱注册，密码加密存储（bcrypt）
* **登录**：JWT 鉴权，返回 access_token + refresh_token
* **用户信息**：获取用户信息、修改昵称/头像/简介
* **关注/粉丝**：

  * 用户可关注/取关他人
  * 查看关注列表、粉丝列表

---

#### 2. 视频模块

* **视频上传**：

  * 支持本地文件上传（MP4）
  * 上传时自动生成封面图（FFmpeg）
  * 限制视频大小（≤ 100MB）
* **视频流**：

  * 推荐流：按时间倒序或算法推荐（后期可扩展）
  * 关注流：仅展示关注用户的视频
* **视频播放**：

  * 支持滑动播放（前端用 Vue 动画切换）
  * 自动加载下一个视频
* **视频详情页**：

  * 显示视频、作者、点赞数、收藏数、评论列表

---

#### 3. 点赞与收藏

* **点赞（Like）**：

  * 用户可对视频点赞/取消点赞
  * 实时更新前端状态
  * 点赞数存储在 Redis（定期同步 MySQL）
* **收藏（Favorite）**：

  * 用户可收藏视频
  * 收藏夹列表展示

---

#### 4. 评论系统

* **评论功能**：

  * 添加评论、删除评论
  * 评论嵌套（一级/二级）
* **评论展示**：

  * 按时间排序
  * 支持分页加载

---

#### 5. 推荐算法（可选增强）

* 简单版：按时间倒序 + 随机抽取
* 增强版（后期可扩展）：

  * 基于点赞、观看时长的个性化推荐
  * 用户偏好画像（Redis ZSet）

---

#### 6. 管理后台（可选）

* 管理员登录
* 视频审核与下架
* 用户封禁/解封
* 举报处理

---

### 四、接口设计（示例）

| 功能    | 方法   | 路径                     | 描述          |
| ----- | ---- | ---------------------- | ----------- |
| 用户注册  | POST | /api/v1/user/register  | 注册新用户       |
| 用户登录  | POST | /api/v1/user/login     | 登录并获取 token |
| 获取视频流 | GET  | /api/v1/video/feed     | 获取视频推荐流     |
| 上传视频  | POST | /api/v1/video/upload   | 上传视频文件      |
| 点赞视频  | POST | /api/v1/video/like     | 点赞或取消点赞     |
| 收藏视频  | POST | /api/v1/video/favorite | 收藏视频        |
| 获取评论  | GET  | /api/v1/comment/list   | 获取评论列表      |
| 发布评论  | POST | /api/v1/comment/add    | 添加评论        |

---

### 五、数据库设计（简要 ER 图）

主要表：

* `user`（用户表）
* `video`（视频表）
* `comment`（评论表）
* `like`（点赞表）
* `favorite`（收藏表）
* `follow`（关注关系表）

---

### 六、性能与扩展

* **缓存层**：视频点赞数、收藏数放入 Redis
* **CDN 支持**：视频可走 CDN 加速
* **异步任务**：上传视频后用 MQ 异步生成封面图
* **监控**：Prometheus + Grafana（可选）
